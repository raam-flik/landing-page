## How to edit

1. Open a page file. Sections are in the same order as the page, top to bottom.
2. Change the text **after** each label, for example:
   `- **Headline (H1):** Funding built for growing brands.`
3. **Keep the labels** (`Headline (H1)`, `Text`, `Button` and so on) and the section headings. They tell the AI where each line goes.
4. **Grey part** is the lighter second half of a heading.
5. Lines under *"Example text inside the product mockup"* are the small words inside the fake screenshots. Change them only if you need to.
6. Each page starts with **Things to confirm**: open questions and placeholders. Tick them off (`- [x]`) or write your answer next to them.
7. To leave a note instead of an edit, start the line with `> Note:`. For example: `> Note: add a section about Ramadan here.`

## Writing style

- **English first.** The Bahasa Indonesia version (`/id/`) comes after the English copy is approved.
- **Tone:** calm and clear, like stripe.com. Short sentences, no hype.
- **Money:** `Rp1.250.000` or `Rp250 jt` (words in prose are fine: "Rp 100 million"). **Dates:** `12 Oct 2026`. **Phone:** `+62 812-3456-7890`.
- Only use numbers and customer names we are allowed to show publicly. This folder is **public on GitHub**.

## When you're done

Pick whichever is easiest:

- **Edit on GitHub:** click a file, then the pencil icon, then **Commit changes**. This needs edit access to the repository.
- **Send the files:** download the files you changed and send them to the team, or upload them to an AI chat together with `AI-GUIDE.md`.
- **Send the link:** give an AI this folder's GitHub link and ask it to *"apply the content edits in `content/` to the pages, following `content/AI-GUIDE.md`"*.
